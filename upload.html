Publish the resume

Drop a PDF, check it renders, then commit it to the repository. Once the commit lands, the resume page shows the document to everyone with a viewer and a download button.

The key that opened this page is a lock, not a security boundary.

The site is static and the repository is public, so the check itself is readable by anyone who looks. What actually protects the repository is the token below: without one, nobody who reaches this page can write a single byte.

Drop the resume PDF here

or press to browse. PDF only, up to 20 MB.

Use a fine-grained personal access token scoped to saikeshavareddych.github.io only, with Contents: read and write, and a short expiry. Create one at github.com/settings/personal-access-tokens/new.

The token is read when you press Publish, used for that one request to api.github.com, and cleared from the field afterwards. It is never written to local storage, a cookie, or any other host. Reloading this page loses it, which is intended.
