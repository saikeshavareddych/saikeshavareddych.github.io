Five builds

Reference architectures I designed and ran myself. Each one is written up the way I would defend it in a review: the constraint that shaped it, the decisions I made, what each decision cost, and the part I got wrong.

These are lab builds, not client work. I have not attached anyone else's name or numbers to them. What I can do is walk through any decision in any of them, including the ones that turned out badly.

landing-zoneterraform

Multi-cloud landing zone

One Terraform module set standing up governed AWS and Azure estates in parallel. Per-cloud network idioms, one shared control plane for state, policy, drift and cost.
